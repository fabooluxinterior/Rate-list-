# Arc Designs — Rate Card

Single-page rate card for **Arc Designs** (@arc.designs_), freelance interior design.

- `index.html` — the whole site (HTML, CSS and JS in one file)
- `favicon.png` — the Arc Designs mark

## Editing
- **Prices and package details:** edit the `PLANS` list near the top of the `<script>` in `index.html`.
- **Email for the Mail button:** change `CONTACT_EMAIL` at the top of the `<script>`.
- **WhatsApp number:** change `WHATSAPP` (country code + number, no `+`).

## Hosting
Served with GitHub Pages from the `main` branch (root folder).
